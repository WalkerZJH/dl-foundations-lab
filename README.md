# DL Foundations Lab

本仓库用于记录近期深度学习与 NLP 入门任务的学习过程、代码实现和阶段性交付成果。

## 仓库结构

* `units/`：按任务单元组织代码、笔记和实验结果。
* `deliverables/`：正式交付材料，按周组织。
* `docs/weekly/`：每周进展记录。
* `data/`：数据集说明目录，原始数据不上传。
* `checkpoints/`：模型参数说明目录，参数文件不上传。
* `logs/`：训练日志说明目录，大体积日志不上传。

老师查看正式成果时，优先查看 `deliverables/` 目录。
